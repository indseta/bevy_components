# Bevy Components importer

Reads the `bevy_components` glTF extras exported by the Blender addon and inserts the matching Bevy and Avian components. See the [main README](../README.md) for installation.

- **Visibility Range**: `VisibilityRange` on mesh descendants of the object.
- **Collider**: cuboid, sphere and capsule colliders go on the object itself, so they also work on empties. Triangle mesh and convex hull colliders are built from each mesh under the object. Each collider gets Avian `Friction`, `Restitution` and `CollisionLayers`. Layer N is bit N of `LayerMask`, so it matches the Nth variant, counting from 0, of a `#[derive(PhysicsLayer)]` enum. Defaults to a static body when neither the object nor a parent has a Rigid Body.
- **Rigid Body**: Avian `RigidBody` on the object. A set Mass on a dynamic body becomes `Mass` plus `NoAutoMass`, so it is the total mass of the body and its child colliders. Without one, Avian computes the mass from the collider volumes at 1 kg per cubic meter. Colliders on child objects join the nearest parent's body, so an empty with a Rigid Body can hold child empties that each carry a collider shape. Dynamic bodies also get `GravityScale`, `LinearDamping`, `AngularDamping` and `LockedAxes`. Continuous Collision set to All Bodies or Off becomes `SweptCcd` with `CcdFilter::ALL` or `CcdFilter::NONE`; the default keeps Avian's sweeping against static and kinematic bodies. Kinematic and dynamic bodies start with `LinearVelocity` and `AngularVelocity` in world space, zeroed on locked axes.
- **Joint**: an Avian `FixedJoint`, `RevoluteJoint`, `PrismaticJoint` or `SphericalJoint` on a new child entity of the object, named `<object> joint`, since Avian joints cannot sit on a rigid body. Its frames come from the object's position and rotation, so the bodies keep their spacing from Blender and limits count from there. Bodies are found by object name within the same scene, and a name that is not found skips the joint with a warning. An empty Body 1 or Body 2 pins the other body to a static `<object> anchor` entity under the scene root. Hinges, sliders and ball joints get `JointDamping`, and every joint gets `JointCollisionDisabled` unless Collide Bodies is on.
- **Shadows**: `NotShadowCaster` and `NotShadowReceiver` on mesh descendants of the object, unless a closer object has its own Shadows.
- **Audio Player**: `AudioPlayer` and `PlaybackSettings` on the object. Autoplay off creates the sink paused, so call `play()` on its `AudioSink` or `SpatialAudioSink` to start it. Spatial sounds set `spatial_scale` to one over the Distance, so Bevy plays them at full volume within it and quieter by the square of the distance beyond it. Add `SpatialListener::new(0.2)` to your camera or player to hear them in 3D. Bevy's default listener puts the ears 4 m apart, which makes nearby sounds quieter than the Distance says. Bevy loads `.ogg` by default; `.wav`, `.mp3` and `.flac` need its `wav`, `mp3` and `flac` features. Needs Bevy's `AudioPlugin`, and is skipped with a warning without it.
- **Scene Reference**: `WorldAssetRoot` on the object with the referenced scene, its path resolved relative to the scene that holds it, so references inside referenced scenes work too. A reference back to its own scene is skipped with a warning.
- **Animation**: an `AnimationGraph` with the clip named after the Blender action, played with its repeat and speed on the glTF `AnimationPlayer` on the object or its closest parent. Each glTF scene root gets `SceneAnimations`, a map from clip names to handles.
- **Light**: the shadow, radius, bias and intensity settings on the `PointLight`, `SpotLight` or `DirectionalLight` that Bevy's glTF loader spawns under the object, plus `CascadeShadowConfig` for custom sun cascades and `VolumetricLight` when Volumetric is on. Baked lights set `affects_lightmapped_mesh_diffuse` to false. Area lights become a `RectLight` on the object.
- **Ambient Light**: the `GlobalAmbientLight` resource, from the scene's extras.
- **Custom**: `BlenderCustomComponents` with the type path and JSON value, for your game to map to its own components. Components with fields defined in Blender arrive as a JSON object that `serde_json::from_value` reads into a struct with the same field names, including `Vec3` and `Color` fields.
- **Fog Volume**: a child entity with Bevy's `FogVolume`, scaled to the box. Cameras need `VolumetricFog`, and a light needs `VolumetricLight`, which the Light component's Volumetric adds.
- **Reflection Probe**: a child `LightProbe` scaled to the box, with a `GeneratedEnvironmentMapLight` from the cubemap embedded in the GLB once it has loaded, and `ParallaxCorrection::None` when Parallax Correction is off. The embedded textures are listed in `GltfTextures` on the object.
- **Irradiance Volume**: a child `LightProbe` scaled to the box, with an `IrradianceVolume` from the 3D texture embedded in the GLB. It also lights meshes that have lightmaps.
- **Compressed textures**: KTX2 textures from the exporter's Texture Compression option are converted at load time to ASTC, BC7, ETC2 or RGBA, whichever the GPU supports, without changing how you load the scene.
